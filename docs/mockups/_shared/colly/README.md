# Colly — les images

Découpées de la planche de personnage fournie par le quartier
(`WhatsApp Image 2026-08-21`). Colly est « la créature des Halles de la Cartoucherie » :
ventouses pour grimper partout, sociable et curieuse, toujours partante pour une rencontre.

| Fichier | Ce que c'est | Où s'en servir |
|---|---|---|
| `colly-couleur.png` | Colly en couleur, fond détouré (transparent) | l'accueil, l'illustration principale, le flyer |
| `colly-salut.png` | Colly qui fait « Salut ! » | accueil d'un nouveau voisin, page à propos |
| `colly-joyeux.png` | expression joyeuse (crayonné) | confirmation, avis publié |
| `colly-triste.png` | expression déçue (crayonné) | aucun résultat, page 404 |

Les trois expressions sont au crayon sur la planche d'origine, pas en couleur : elles
s'utilisent en petit et en niveaux de gris, ou se redessinent plus tard dans la palette.
`colly-couleur.png` est la seule version couleur disponible aujourd'hui.

que l'association a bien le droit d'utiliser ces images.
